# Estação Meteorológica Inteligente de Baixo Custo

Este projeto tem como objetivo o desenvolvimento de uma estação meteorológica
inteligente de baixo custo, capaz de coletar e transmitir dados ambientais em
tempo real utilizando um microcontrolador e sensores integrados.

## Objetivo
Desenvolver uma solução embarcada para monitoramento de variáveis ambientais,
permitindo a visualização local e o envio dos dados via rede Wi-Fi para
aplicações externas.

## Tecnologias Utilizadas
- Microcontrolador: Raspberry Pi Pico W (RP2040)
- Linguagem: C/C++
- Comunicação: Wi-Fi / MQTT
- Sensores ambientais
- Display para visualização local

## Funcionalidades
- Coleta de dados ambientais
- Processamento local no microcontrolador
- Envio de dados via Wi-Fi
- Exibição das informações em display

## Estrutura do Projeto
- `/src` – Código-fonte principal
- `/drivers` – Drivers de sensores e periféricos
- `/include` – Arquivos de cabeçalho
